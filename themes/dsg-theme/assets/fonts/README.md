# Fonts

Self-hosted, so visitors' browsers never contact Google Fonts. Both are variable fonts (one file covers every weight), Latin subset, from [Fontsource](https://fontsource.org).

| File | Font | Weights | License |
|---|---|---|---|
| `schibsted-grotesk-latin-wght-normal.woff2` | Schibsted Grotesk | 400–900 | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | 100–800 | SIL Open Font License 1.1 |

They're registered in `theme.json` under `settings.typography.fontFamilies`.
